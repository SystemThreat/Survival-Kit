2 · Connect no DNS needed

A new node finds peers through DNS seeds. If those are gone, give it addresses by hand. Add these lines to nex.conf (or pass them as -addnode=):

addnode=172.96.186.49:9333
addnode=198.252.107.13:9333
addnode=103.119.217.105:9333
addnode=198.252.101.117:9333
addnode=54.20.130.14:9333

One answering peer is enough: it tells your node about every other node it knows. Then ask what you found:

nex-cli getconnectioncount
nex-cli getpeerinfo

DNS seeds, used automatically while they work:

seed.xcoinproject.com   seed.superknet.com   seed.xcoinminer.com
seed.minedifferent.com  seed.movepunk.com

5 · Mine pools are optional

Mining needs only your own node and an xpa1r… address you control. Solo mining pays the whole block to you.

  1. Run nexd and wait until nex-cli getblockchaininfo shows it caught up.
  2. Point a MetalDAG miner at your own node with your payout address.
  3. Never mine on a node that has no peers: its blocks may be on a chain nobody else follows.

Check a mirror is genuine: every mirror serves manifest.json and its signature manifest.json.sig next to this page. With allowed_signers (the public release key) and two stock commands:

ssh-keygen -Y verify -f allowed_signers -I release@xcoinproject \
  -n xcoin-survival -s manifest.json.sig < manifest.json
shasum -a 256 index.html    # must equal "index.html" in manifest.json

Run your own mirror: anyone may, on their own onion address. The mirror kit and its checker are free (MIT); this page is public domain (CC0).

Keep your own copy: save this page. It is one file and works offline. If you run a node, host a mirror too and tell the community.
