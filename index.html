2 · Connect no DNS needed

A new node finds peers through DNS seeds. If those are gone, give it addresses by hand. Add these lines to nex.conf (or pass them as -addnode=):

addnode=172.96.186.49:9333
addnode=198.252.107.13:9333
addnode=103.119.217.105:9333
addnode=198.252.101.117:9333
addnode=54.20.130.14:9333
addnode=136.118.128.212:9333

One answering peer is enough: it tells your node about every other node it knows. Then ask what you found:

nex-cli getconnectioncount
nex-cli getpeerinfo

DNS seeds, used automatically while they work:

seed.xcoinproject.com   seed.superknet.com   seed.xcoinminer.com
seed.minedifferent.com  seed.movepunk.com

5 · Mine pools are optional

Mining needs only your own node, the small pool program that ships with the source code, and an xpa1r… address you control. Solo, a block you find pays its whole reward to you, with no fee.

  1. Run nexd and wait until nex-cli getblockchaininfo shows it caught up. Never mine on a node with no peers: its blocks may be on a chain nobody else follows.
  2. Start your own pool next to it, from the source folder (solo by default, standard Python only): 
    XCOIN_RPC_COOKIE="$HOME/.nex/.cookie" XCOIN_NATPMP=0 \
XCOIN_STATS_DIR="$HOME/.xcoin-pool" python3 xcoin-pool/xcoin-pool.py
    On macOS the cookie is "$HOME/Library/Application Support/NEX/.cookie". XCOIN_NATPMP=0 keeps the port off your router.
  3. Point a MetalDAG miner at it. NerdMiner on an Apple Silicon Mac: 
    ./NerdMiner xpa1r…your-address --pool 127.0.0.1:3333 --base 1790380800 --worker mymac
    --base 1790380800 is the genesis time (2026-09-26 00:00 UTC), which sets the MetalDAG epochs. It must be exactly this number.

Ordinary Bitcoin SHA-256 machines (ASICs) cannot mine xCoin: MetalDAG is a different proof of work.

7 · Sealed commitments proof of what was known, and when

A sealed commitment proves the project knew something on a given date without saying what, until it is revealed. Its fingerprint, SHA-256 of xcoin-commit/1|text|salt, is put into an xCoin transaction, so the block's time is the proof. Once revealed, anyone can recompute it and find it already in that block.
